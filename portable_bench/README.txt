LBS vs DQS Benchmark Portable Suite
============================================================
System Requirements:
- Windows 10 or 11 (64-bit). No Visual Studio runtime required.
- Any GPU with OpenGL 3.3 support (NVIDIA, AMD, or Intel).

Machine Preparation:
1. Plug in AC power charger (laptops throttle on battery).
2. Set Windows Power Mode to 'Best Performance'.
3. Close web browsers and background GPU/CPU-heavy apps.

How to Run:
- Double-click 'run_bench.bat' (runs E2 & E3 in ~9.5 minutes).
- Outputs 'results_%COMPUTERNAME%.zip' containing all CSVs.
- Send 'results_%COMPUTERNAME%.zip' to the benchmark team.
